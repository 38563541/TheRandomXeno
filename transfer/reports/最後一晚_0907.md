## 階段 1：nn.Sequential 向後相容修復

### 程式碼變更

`models/stage2_model.py`：

```python
depth = getattr(args, "intra_depth", 1)
if use_intra:
    if depth == 1:
        self.intra = IntraRelation(rel_dim, num_heads)  # 保留舊鍵名（向後相容）
    else:
        self.intra = nn.Sequential(*[IntraRelation(rel_dim, num_heads)
                                     for _ in range(depth)])
else:
    self.intra = nn.Identity()
```

### 驗證結果

- **V1 PASS**：depth=1（B4 true_hyrsm checkpoint50000.pt），intra type = IntraRelation，`load_state_dict` 無 intra key 錯誤
- **V2 PASS**：depth=2（B2-x2 checkpoint25000.pt），intra type = Sequential，`load_state_dict` 無 intra key 錯誤

### 效果

- 所有舊 B4/B2/B3 checkpoint（depth=1）鍵名不變（`transformers.0.intra.norm1.weight`），可正常載入
- B2-x2 checkpoint（depth=2）鍵名有 `.0.`/`.1.`，仍可正常載入
- 向後相容，不影響新訓練（B2-x2 用 depth=2 分支）
