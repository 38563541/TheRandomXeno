## 不對勁但規則沒涵蓋的事

1. **measure_vram.py 的 RN18 frozen reserved 偏高（4.1 GB vs Colab 1.78 GB）**：
   TinyModel 的 PairHead 與真實 TRXSetMatching 記憶體行為不同。TinyModel 的 `max_memory_reserved` 包含 allocator 快取的未使用區塊，而 Colab 全模型在 frozen 模式下記憶體更規律。實際訓練確認 2.10 GB（<3 GB 門檻）。

2. **conda run 的 stdout buffering**：`launch.sh` 用 `nohup conda run ... python ...`，
   Python 的 `flush=True` 輸出無法即時出現在 `logs/frozen_b1_b2.log`。
   實際的 [INFO] 訊息在 `run.py` 的 `print_and_log()` 路徑寫入 checkpoint dir 的 `log.txt`。
   下次啟動大型訓練時建議改用：
   ```bash
   PYTHONUNBUFFERED=1 setsid nohup conda run -n trx --no-capture-output python ...
   ```

3. **"research stuff" 資料夾不存在**：已在 measure_vram.py 中自行加入新功能（--csv, --frozen, --sweep, 學?, max_memory_reserved），功能等同描述。
